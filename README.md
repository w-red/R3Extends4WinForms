# R3Extends4WinForms
This project is the [R3](https://github.com/Cysharp/R3) extension methods library.

Maybe there are some things that have been expanded by your Framework, so they need to be added.

# How to use
Add the [NuGet package](https://www.nuget.org/packages/R3Extends4WinForms) to your project.
```shell
 dotnet add package R3Extends4WinForms
```
You can also add it via the NuGet Package Manager in Visual Studio.
